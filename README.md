# volleyball_computer_vision
This project will try to analyse through computer vision a volleyball match.

Yolo26n will be the model chosen for detection.

This video will be used for the final result of the model.
https://www.youtube.com/watch?v=RGyQH0p60e4

This is the dataset for training the ball
https://universe.roboflow.com/volleyballrefereelabel/volleyball-ball-nd3dz/dataset/1#

This is the dataset for training the players
https://universe.roboflow.com/protovision/volleyball-players-gamca/dataset/1

This is the dataset for training the court
https://universe.roboflow.com/volleyballcourt/volleyball-court-keypoints-k6y7r/dataset/1#
